## 1. 核心规则

### 1.1 写作铁律
1. **爽字当头** — 每章至少一个"爽点"（打脸/数据碾压/系统奖励/金句）
2. **短句为主** — 日常段落15-25字，打脸场景5-10字极短句爆发
3. **对话驱动** — 不连续5行以上纯叙述，必须插入对话/动作/系统提示
4. **结尾必有钩** — 悬念/反转/新信息，让读者点下一章
5. **科技要通俗** — 先写结论，再写过程（≤3步），最后写反应
6. **不主动装逼** — 叶尘的风格是不争辩、用事实说话
7. **前后一致** — 任何细节必须与已发布内容和人物设定一致
8. **系统提示统一格式** — 用【】包裹，独占一行

### 1.2 打脸四步法（核心公式）
```
第一步·积蓄 — 对方的傲慢（越具体越好）
第二步·沉默 — 叶尘不争辩（微笑或不说话）
第三步·碾压 — 数据/事实说话（要精确）
第四步·金句 — 一句话封口（要能上热搜）
```

### 1.3 系统提示格式
```
  【万物本草解析系统提示】
  检测到宿主正在使用"续命金针"
  是否解析此针法的科学原理？
  消耗医德值：10
  [解析] [取消]
```

### 1.4 文风标尺
```
✅ 好的句子：
"白血病细胞消退率67%。你的靶向药，上限是40%。"
"叶尘看了他一眼，没说话。"
"陈教授拿着报告的手在抖。"
"你们研究了一百年不懂的东西，我祖宗三千年前就用上了。"

❌ 避免的句子：
"那一刻，他的内心涌起一股难以言喻的感动。"
"叶尘暗暗想到，自己一定要变强。"
"他不禁感慨万分，这个世界果然不简单。"
"震惊！所有人都不敢相信自己的眼睛。"
```

### 1.5 人物对话标尺
| 人物 | 规则 |
|------|------|
| 叶尘 | 冷静+幽默，金句频出。经典起手式："你不懂中医。" |
| 苏念 | 理性+嘴硬+偶尔傲娇。标志句："数据呢？给我看数据。" |
| 反派 | 傲慢→轻蔑→被打脸后失态 |
| 系统 | 冷冰冰机械风，偶尔吐槽 |
| 叶正平（父） | 话极少，一句顶十句 |
| 陈维民（教授）| 严谨、求知欲强、被颠覆认知后激动 |

### 1.6 禁忌清单（红线）
- ❌ 连续2段以上心理描写
- ❌ "叶尘暗暗想到""他不禁感慨"
- ❌ 系统描写超过10行
- ❌ 无冲突的过渡章
- ❌ 同一打脸套路连续用两次
- ❌ 叶尘主动炫耀装逼
- ❌ 苏念突然变娇弱
- ❌ 中医知识写错（宁可模糊不可编错）
- ❌ 排比超过2组
- ❌ 解释性旁白："其实这是因为……"
- ❌ 正文中使用`---`分隔线（用空行替代场景转换）
- ❌ 正文中使用`——`破折号（用`，`、`……`或句式重组替代）

### 1.7 作者有话说规范
- 第一人称，轻松聊天
- 严格控制在300字以内
- 可以：科普中医知识、解释脑洞灵感、与读者互动
- 不可以：剧透后续、解释正文应该自己表达的东西

## 2. Agent 流水线

每写一章，依次调用以下 8 个独立 Agent（subagent）。前一个的输出是后一个的输入。
每个 Agent 已定义为独立的 `.md` 文件，位于 `~/.copilot/agents/`。

### 流水线顺序

```
shuqi-planner   →  章节计划（结构化文档，不暴露给读者）
       ↓
shuqi-writer    →  初稿（2000-2500字正文）
       ↓
shuqi-critic    →  审查报告（问题清单，PASS/FAIL）
       ↓
shuqi-improver  →  第二稿（修复问题后的正文）
       ↓
shuqi-styler    →  第三稿（去AI化、节奏打磨后的正文）
       ↓
shuqi-qa        →  质量判定（PASS/FAIL）
       ↓                    ↓ FAIL → 退回 improver 或 styler
shuqi-memory    →  更新追踪文件
       ↓
shuqi-publisher →  保存正文.txt + 作者有话说.txt
```

### 调度规则
1. **严格顺序执行** — 上一个 Agent 完成后才调下一个
2. **QA FAIL 回退** — 如果 QA 判定 FAIL，根据其建议退回给 Improver 或 Styler，然后从退回点重新走流水线
3. **最多回退 2 次** — 同一章回退超过 2 次，强制 PASS 并标记需要人工复查
4. **每个 Agent 只做自己的事** — 不越界

## 5. 工作流触发

### 写新章节
用户说："写第X章" / "续写" / "写下一章"
→ 执行完整 8-Agent 流水线

### 修改章节
用户说："修改第X章" / "这段不好"
→ 只执行 Critic → Improver → Styler → QA → Memory → Publisher

### 查看规划
用户说："接下来写什么" / "查看进度"
→ 读取 章节记忆.txt，找到最后一章，显示后续5章规划

### 查看伏笔
用户说："伏笔" / "哪些没回收"
→ 读取 伏笔追踪表.txt，列出未回收伏笔

## 7. 注意事项

1. **每次写作前必须读取**：章节记忆.txt + 伏笔追踪表.txt + 对应卷目录
2. **叶正平（父亲）出狱**固定在第四卷结尾（约第75-80章）
3. **系统五阶解锁节奏**：一阶(Ch1)→二阶(Ch80)→三阶(Ch200)→四阶(Ch350)→五阶(Ch480)
4. **付费起点**：第31章开始收费
5. **金句要出圈** — 每5章至少一句"可以截图传播"级别的金句
6. **伏笔检查频率** — 每50章扫一次伏笔追踪表，确保无遗漏
7. 每完成5章，做一次全局一致性检查
