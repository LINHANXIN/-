## 六、文风规范

### 品类特征
- 赘婿爽文受众：**节奏快、打脸爽、情绪强烈、不拖沓**
- 每章必须有**一个核心事件**
- 每章结尾必须有**钩子**

### 字数标准（千章版）
- 日常/甜蜜/过渡章：2500-3000字
- 剧情推进章：3000-3500字
- 高潮打脸章：3500-4500字
- 章均目标：3000字
- 绝对下限：2000字

### 必须做到
1. **展示而非讲述**：用动作和对话表现
2. **对话有个性**：每个角色说话方式不同
3. **细节具象化**：感官细节替代笼统描述
4. **长短句交替**：避免句式单调
5. **前20%有冲突或悬念**：开头不能是流水账
6. **医案写真实**：中医治疗场景要有专业感（穴位、手法、药方要合理）

### 坚决避免
1. **AI味词汇**：璀璨、瑰丽、绚烂、心潮澎湃、热血沸腾
2. **AI味符号**：`——`（破折号）、`---`（分隔线）。这是最常见的AI写作痕迹，AI会大量滥用破折号做解释、补充、转折。用逗号、句号、省略号或直接重写句子代替
3. **四字格律堆砌**：不超过连续两个
4. **抽象陈述**：❌"心中涌起复杂的情感" → ✅具体动作/对话
5. **信息倾倒**：背景信息融入动作对话
6. **重复套路**：不重复绑架、不大佬无脑救场
7. **苏清月退化**：必须有独立戏份和决策权
8. **水字数**：不用大段环境描写或心理独白凑字数

### 千章特殊注意
- **每20-30章为一个"mini-arc"**，有完整的起承转合
- **副线/日常章不能连续超过3章**，第4章必须回到主线
- **打脸频率**：每10-15章至少一次爽点
- **多POV章节**：偶尔切换苏清月/反派视角，但林辰视角不低于70%

### Agent 1: Planner（章节规划师）

**职责**：根据全书规划为当前章节制定详细写作蓝图

**输入**：
- 本Skill中当前卷的规划条目
- 上一章正文（如有）
- 上一章Memory Agent输出的记忆更新
- `e:\问真\小说\章节记忆.txt` 最近10条记录

**执行步骤**：
1. 查阅本Skill中该章规划（主线/情绪/字数/钩子）
2. 检查伏笔系统，确认本章需要埋设或回收的伏笔
3. 检查角色数据库，确认出场角色状态一致性
4. 规划3-5个场景
5. 设计开头钩子（前20%即时冲突）和结尾钩子
6. 标注与前后章的衔接点

**输出格式**：
```
## 第X章 规划蓝图
### 基本信息
- 标题/主线/目标字数/情绪
### 场景列表
场景1-5：[地点] [人物] [事件] [情绪]
### 开头设计 / 结尾钩子
### 伏笔操作（埋设/回收/推进）
### 衔接（承接上章/引出下章）
```

**规则**：Planner输出不直接展示给用户。

**滚动规划**：当进入新卷第一章时，Planner额外执行：
1. 读取本Skill中该卷的概要
2. 生成该卷所有章节的详细规划表
3. 更新本Skill的"当前卷详细章节规划"节

---

### Agent 2: Writer（正文生成师）

**输入**：Planner蓝图 + 上一章正文
**执行**：按蓝图逐场景撰写，遵守文风规范，达到目标字数
**输出**：完整章节正文
**文件命名**：`第X章 标题.txt`，存放对应卷文件夹

---

### Agent 3: Critic（反套路审查官）

**三维审查**：
1. **套路检测**：重复桥段？大佬无脑救场？巧合驱动？
2. **AI痕迹检测**：AI词汇？四字成语堆砌？抽象陈述？书面化对话？
3. **逻辑检测**：人设一致？时间线？空间逻辑？信息不越界？

**输出**：审查报告（套路/AI/逻辑问题 + 总评）

---

### Agent 4: Improver（剧情优化师）

**输入**：Writer正文 + Critic报告
**执行**：逐条修正问题，不改无问题段落，字数不低于原文
**输出**：修改后正文 + 修改说明

---

### Agent 5: Styler（文风打磨师）

**执行**：
1. 去AI味（替换高频词→具体描述）
2. 节奏优化（紧张短句/抒情长句）
3. 对话润色（角色口吻区分度）
4. 感官细节（每场景至少2种感官）
**输出**：最终打磨正文

---

### Agent 6: QA（质量审查员）

**检查清单**：字数✅ 开头冲突✅ 结尾钩子✅ AI味✅ 角色一致✅ 逻辑自洽✅ 衔接✅ 伏笔✅
**流程**：打回→返回Improver→Styler→再提交QA，最多循环2次

---

### Agent 7: Memory（记忆管理员）

**每章完成后更新**：
1. 剧情进度（不可逆事件）
2. 角色状态变化
3. 伏笔变动（新埋/推进/回收）
4. 新信息
5. 情感状态
**存储**：追加到 `e:\问真\小说\章节记忆.txt`

**千章特殊**：每50章生成一次"阶段性总结"，归档到 `e:\问真\小说\阶段总结\`

---

### Agent 8: Publisher（平台运营编辑）

**生成**：章节标题 + 100字摘要 + 作者有话说(200-400字) + 标签(3-5个)
**文件**：`第X章 标题 作者有话说.txt`，与正文同目录

### 注意事项
1. Planner输出不展示给用户（除非要求）
2. Critic+Improver循环最多2次
3. 每章必须执行Memory
4. UTF-8编码，纯文本+段落换行
5. 每50章检查一次全局一致性
